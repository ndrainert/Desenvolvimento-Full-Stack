# Desenvolvimento Full Stack

Repositório de estudos e exercícios práticos desenvolvidos durante a formação em Desenvolvimento Full Stack. O conteúdo é organizado por temas e registra a evolução desde os conceitos fundamentais de programação.

## Conteúdo atual

### Fundamentos

Exemplos introdutórios em JavaScript, organizados por assunto:

- **Início:** sentenças, blocos de código e estrutura básica de programas.
- **Dados:** variáveis, valores, operações e manipulação de dados.
- **Desafios:** exercícios para aplicar os conceitos, como calcular a área de uma circunferência e trocar valores entre variáveis.

```text
Fundamentos/
├── Início/
│   ├── Bloco/
│   ├── Sentença/
│   └── Desafio sentença&bloco/
├── Dados/
│   ├── Desafio área da circunferência/
│   ├── Desafio Troca de Valores/
│   ├── Dados.js
│   ├── Dados2.js
│   ├── Dados3.js
│   └── Dados4.js
└── primeiro.js
```

## Como executar

Os exemplos são scripts independentes e não exigem dependências adicionais. Instale o [Node.js](https://nodejs.org/) e execute um arquivo pelo terminal, a partir da raiz do repositório:

```bash
node "Fundamentos/Dados/Desafio Troca de Valores/Desafio_troca.js"
```

Cada exercício pode ser executado separadamente; consulte os arquivos para ver os conceitos demonstrados e os resultados impressos no terminal.

## Objetivo

Servir como material de aprendizado e referência pessoal, reunindo exemplos e desafios práticos à medida que novos tópicos da formação forem estudados.
